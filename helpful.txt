Start the server in the background:

Bash
pm2 start ecosystem.config.js
View live server logs and chat activity:

Bash
pm2 logs lan-irc-server
Check server status and resource usage:

Bash
pm2 status
Restart the server:

Bash
pm2 restart lan-irc-server
Stop the server:

Bash
pm2 stop lan-irc-server
Make PM2 auto-start the server on system reboot:

Bash
pm2 startup
pm2 save
